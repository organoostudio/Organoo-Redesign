# Organoo Redesign

Redesign prototypes for [organoostudio.com](https://organoostudio.com) — Organoo Studio, a digital agency in Malang, East Java.

Brand: black `#0A0A0A`, white `#FFFFFF`, emerald `#2AA36B`. Type: Manrope + Instrument Serif.

## Prototypes

| Folder | What it is |
| --- | --- |
| `prototypes/motion` | **Organoo Studio Motion** — option 1 with the enhanced motion layer, scroll-scrubbed hero video, gradient-blur nav and curtain footer with the spotlight wordmark. Current main direction. |
| `prototypes/home` | **Organoo Studio Home** — the home page on its own, with the scroll-scrubbed hero. |
| `prototypes/website` | **Organoo Studio Website** — option 1 baseline (all pages, hash-routed). |
| `prototypes/growth-lab` | **Organoo Growth Lab** — option 2, alternate palette and scroll effects (kept for reference). |

Each prototype is a single static `index.html` with its images and video beside it. Open it through any static server, for example:

```bash
npx serve prototypes/motion
```
