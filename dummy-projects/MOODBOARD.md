Dummy websites built for the Organoo Studio portfolio (target: US / EU / AU clients). All are fully client-side. The fictional brands carry a "Demo · Organoo Studio" badge; Sangkarloka is Organoo's own real brand. **Light mode is always the default view** (the pages ignore the viewer's system/app theme); SaaS dashboards have an optional dark toggle that is not remembered between visits.

  - **Member card** (`#member`):
    - Log in by ID or email; 5 demo members cover active, expiring, expired, frozen and off-peak.
    - Shows a QR code that changes every 30 s (signed token `FORMA|id|window|code`), a 6-digit backup code, status, days left, monthly visit heatmap and streak.
    - Also my classes, renew/extend (1/3/12 months) and freeze 7/14/30 days.
  - **Front-desk scanner** (`#scan`):
    - Camera scanning via the BarcodeDetector API (Chrome Android/macOS), plus manual ID + 6-digit code entry.
    - Rules: signature check; code older than 60 s = "possible screenshot"; expired; frozen; Off-Peak outside weekdays 10:00–16:00; second entry within 3 h = "possible card sharing", with a staff override after a photo check.
    - Expiring ≤ 7 days is allowed with a warning.
    - Shows a big member photo for face verification, plays a beep and keeps a recent-scans log.
    - A "Demo tools" phone simulator can scan a live card, a 2-minute-old screenshot, the same card twice, or type the code.
  - **Admin** (`#admin`, demo PIN 2468):
    - KPIs, 14-day and by-hour charts, live feed (updates across tabs via the storage event), expiring-soon list.
    - Check-ins table with date/club/result filters and CSV export (artifact `downloads` capability; blob fallback when self-hosted).
    - Members table with status filters, and a member drawer (extend, freeze, email/WhatsApp reminder, 5-week heatmap, activity).
    - Alerts list of denied entries with "mark reviewed".
  - The QR encoder was written from scratch (`src/qr.js`, byte mode, ECC M, versions 1–6) and verified with OpenCV. No external libraries.
  - Demo dataset: 48 seeded members with 45 days of check-in history, plus anything done in the browser (localStorage).
- **Join flow:** plan → details (photo upload for the card, age check 16+) → demo payment (Luhn, 4242 test card) → a new member is created with ID FM-2xxx and appears in the admin.

## 9. Strata Atelier (Architecture / Interior / Creative Studio: fictional studio, "award-style")
- **Brief from Organoo:** a space to experiment with Awwwards-style design. Reference: larkstudio.id (Bogor architecture & interior studio), plus three videos (the "House" and "Northwall" templates, and ELYSE again). Organoo's focus: **cinematic 3D property objects**.
- **Brand:** Strata Atelier, architecture, interiors, landscape and 3D visualisation, with studios in Melbourne and Copenhagen (live clocks in the nav). English only. Budgets and Lab costs in AUD/EUR/USD.
- **Fonts:** Syne (display), Inter Tight (UI), JetBrains Mono (technical labels).
- **3D engine (`src/engine.js`):**
  - three.js r160 loaded from cdn.jsdelivr.net via an import map; a WebGL-less fallback shows photos instead.
  - Six procedural buildings generated in code (no model files): Cliff House (parametric), gabled fjord cabins, 7-floor residential tower, brick courtyard house, glass pavilion café with interior, hillside terraces.
  - Each part belongs to a stage (site, structure, envelope, glass, landscape) so buildings can "build themselves": ink edge lines draw in, volumes rise, materials fade from white maquette to real colour.
  - Sun study from 06:00 to 21:00 (sky dome, golden hour, dusk with glowing windows, glow sprites and a lit pool), section cut (clipping plane), exploded floors, Render / Model (maquette) look, camera presets (aerial, eye level, axo, plan), drag orbit with inertia, wheel zoom, 3D-anchored hotspot notes, and PNG stills via the artifact `downloads` capability.
- **Home, top to bottom:**
  - Loader: a house line drawing plus 000–100 counter.
  - Hero + pinned cinematic sequence (scroll-driven): giant "Strata Atelier" type over an ink sketch of the Cliff House; letterbox bars, timecode and chapter HUD; chapters 01 Site → 02 Structure → 03 Envelope → 04 Light (sun sets, windows glow) → 05 Landscape, ending on "Built from light." with a link to the project.
  - Statement with words that fill on scroll, count-up numbers.
  - Selected work index (big rows with cursor-following photo preview).
  - "The model room": dark section with a live 3D viewer and tabs for all six models.
  - Four disciplines, pinned process (six steps with a 3D-tilting photo), team, journal, marquee and magnetic "Start a project" CTA, footer with oversized wordmark.
- **Other pages:** Work (type filter, grid/index), 6 project pages (photo hero, story, facts, live 3D viewer with hotspot list, gallery + lightbox, material palette, team, next project), **Massing Lab** (parametric house: floors, cantilever, glazing, facade material, pool, roof garden, time of day; live floor area, cost, embodied carbon and solar readout; "send to studio" pre-fills the brief), Studio (story, team modal, awards, careers), Journal (3 articles with reading progress), Start a project (brief form with budget slider and validation, stored in localStorage; studio-visit booking with Google Calendar link).
- **Motion:** custom cursor with labels, curtain page transitions, split-word title reveals, film grain, nav that hides on scroll and inverts over dark sections.
- **Content honesty:** studio, people, awards and figures are fictional (demo badge). Team photos are stock models. Project photos are stock images and the page says so.

- **Testing note:** the container cannot reach cdnjs/jsdelivr, so three.js r160 was fetched with a sparse `git clone` from GitHub (git works; the CDNs and npm do not) and served locally for Playwright + SwiftShader tests.

AI responses (Tandem) are rule-based and generated from demo data. No API key or backend is needed for any demo.
